Every entry includes the author, source post, date and evidence note. Linked demos and repositories are included only where identified. These are creator examples, not controlled benchmarks or an official model specification.

## Take the collection with you

The JSON and preview images live **in this repository**. No CMS account, API key, scraping step or build is needed to use a checkout.

```sh
git clone https://github.com/TripoGrowthLab/awesome-astra-prompts.git
cd awesome-astra-prompts
```

```js
import { readFileSync } from 'node:fs';

const { prompts } = JSON.parse(readFileSync('data/prompts.json', 'utf8'));
const chinese = JSON.parse(readFileSync('data/locales/zh.json', 'utf8'));

// Find examples with a project repository.
const withCode = prompts.filter(p => p.links.repository);
console.log(withCode.map(p => ({ title: p.title, repository: p.links.repository })));

// Get a complete localized prompt and its source attribution.
const example = withCode[0];
console.log(chinese.prompts[example.id].prompt);
console.log(example.author, example.source.url, example.evidence.kind);
```

| File | What you get |
| --- | --- |
| [data/prompts.json](data/prompts.json) | All English records, sources, evidence, project links and local preview paths |
| [data/locales/](data/locales/) | Complete localized content, keyed by the same stable IDs |
| [data/repositories.json](data/repositories.json) | Distinct linked repositories and the examples they support |
| [data/manifest.json](data/manifest.json) | Snapshot date, coverage counts and JSON checksums |
| [assets/previews/](assets/previews/) | Deduplicated source previews, stored as WebP |
| [schema/prompt.schema.json](schema/prompt.schema.json) | Collection schema, including prompt and localized-record definitions |

See the [data guide](data/README.md) for the field contract and optional maintenance exporter. The collection can be maintained with plain JSON; it does not require the Tripo website to run.
