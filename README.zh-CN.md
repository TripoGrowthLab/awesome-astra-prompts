## 从参考到自己的作品

1. **先选你想实现的效果。** 打开案例，看看配图，再去原帖和评论区了解上下文。
2. **按实际需求修改任务。** 补充要用的引擎、操作方式、画面风格和制作范围。有些作品还依赖参考图、已有资产或后续对话。
3. **放到你使用的模型里尝试。** 这些内容是参考，不保证一次就能复现原作。运行第三方项目之前，请先检查代码与依赖。
4. **玩法跑通后，再打磨画面。** 为角色、道具和场景补上更细致的 3D 资产。

### 让你的 3D 场景更精致

游戏能玩、场景能逛之后，还可以把画面再往前推进一步。用图片或几句话，在 Tripo 创建更细致的角色、道具等 3D 资产，再加入你正在搭建的作品。

## 哪些是原始提示词，哪些是整理稿？

- **已公开提示词：** 作者公开分享过的指令。译文保留任务含义，但不等同于原语言的逐字记录。
- **来源整理稿：** 根据作者公开的项目描述，整理成可以尝试的任务要求。它不是作者未公开的原始提示词，也不能保证复现截图中的效果。

每条记录都有作者、原帖、日期和来源说明。找到演示或 GitHub 仓库的，会另外列出。案例不是受控的模型性能测试，也不是官方能力说明。

## 数据和图片都在仓库里

无需 CMS 账号、API Key 或启动网站，克隆仓库后就能读取所有 JSON 和预览图。

```sh
git clone https://github.com/TripoGrowthLab/awesome-astra-prompts.git
cd awesome-astra-prompts
```

英文主表位于 [data/prompts.json](data/prompts.json)，中文完整内容位于 [data/locales/zh.json](data/locales/zh.json)，使用相同的案例 ID 对应。你也可以直接阅读 [中文图文目录](docs/catalog.zh.md)，不需要写代码。

字段约定、校验和维护方式见 [数据说明](data/README.md)。希望批量取用数据，可以参考 [English README 中的 Node.js 示例](README.md#take-the-collection-with-you)。
